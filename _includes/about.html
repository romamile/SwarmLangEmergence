About the Workshop

This workshop explores how swarm robotics, robotic systems inspired by the collective behavior of social insects, can serve as a powerful experimental platform for investigating language emergence. Unlike purely symbolic or disembodied agent based simulations (e.g. bayesian agents, naming games…), swarm robotics provides a physically grounded, decentralized system in which communication, coordination, and emergent behavior can be studied dynamically in a complex real-life environment, in a task driven setup (foraging, navigating…).

After a quick introduction and a live coding demonstration, participants will engage with a pre-prepared simulation environment (with documentation and starter code provided in advance). Participants be given the occasion (in groups or alone) to modify or even code from scratch in an accessible way your own robotic behavior and test your own experimental setup.
